频谱、动态范围、削波、假无损检测等功能<br>

一个音频质量分析器的网页，支持热门音频格式，在上方拖入音频文件，即可查看其名称、大小、时长、有损/无损压缩、Sample Rate、位深度。有损/无损质量等级，基于 FFT 的频谱分析来检测过采样、识别频率截止、测量动态范围，并验证您的高解析度音频是否真实，支持FLAC、WAV、AIFF、ALAC、MP3、AAC、OGG、M4A 和 OPUS格式，提供动态范围测量、削波检测、立体声相关性分析以及自动化质量评级。<br>
假无损检测、过采样检测、频率频谱分析、频谱图可视化、动态范围与响度、格式检测、质量评估<br>
